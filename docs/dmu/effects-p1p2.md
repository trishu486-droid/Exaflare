# P1・P2 のエフェクト：実機に合わせたもの／想定で作ったもの

実機のエフェクトに全部そろえるための一覧（2026-10-15 時点）。ユーザーの方針：できれば実機のエフェクトに全部合わせる。

- **合わせ済み**：ユーザーの動画・画像で見た目を確かめて寄せたもの。
- **想定**：実機を見ずに作ったもの（色・形・出かたを推定）。動画や画像をもらえたら直す。
- 大きさ・時刻などの「数字の推定」は、それぞれの調査メモ（`research-p1.md`・`research-p2.md`）に書いてある。ここは見た目だけ。
- P3 以降は、ほぼ実機の動画を見て寄せてあり、ユーザーも「割と良い」とのことなので今のまま（2026-10-15）。想定のものは P3 のケフカの絵とじしん＆ブラックホールの専用エフェクト（仮の形）、P4 の混沌の水（円）の着弾（予測）、P4 のボスの出現・退場（オリジナル）くらい。P5 は共通の光で、実機に合わせたかの記録はない。
- このツールは 8bit 風なので、実機の見た目は「色・形・出かた・タイミング」を合わせ、細かい描き込みはドット絵に置き換える。

### ツールに入れたもの（2026-10-15、提案画像で OK）

- めらめらファイガ：散開の頭上マーカー（目盛りの輪＋桃色の三角）、頭割り（P5 ミッシングと同じ「く」の字が4方向から囲む形＋残り秒数。足元の大きな輪は大きすぎたのでやめた）、着弾（炎の輪 → 黒い芯の火の玉）。`p1lib.ts` の `spreadMark`・`stackMark`・`makeFireFx`。
- 線：どの楽章も黄色い細い実線。出どころの点の色と場所で見分ける（ユーザー）。第一楽章＝下段の顔（黄）、第二楽章＝重力弾は渦の柱の上（紫）・岩石弾は手（黄）、第三楽章＝睡眠は男の像の胸（桃）・混乱は女神（白っぽい金。色は推定）。
- 波動砲：予告は顔から狙われた4人へ黄色い線＋像の足元に青白い光の玉ともや。光線は白い芯〜水色〜青＋ふちの稲妻。
- 像の上（フィールドの外）にも描けるように、画面の上に重ねる層を作った（`hud.ts` の `topLayerDraw`。ギミックの `drawTop(t, g)` が描く）。像の上の点の位置は `p1lib.ts` の `STATUE_PTS`・`statuePt`（塔が動くと一緒に動く）。

- 波動砲の予告：もやではなく、像の前に大きな水色の光の球（真ん中が白・渦の筋）。光線はこの球から撃つ（ユーザー 2026-10-15）。
- 混乱の頭上の印（桃色の輪）はなくした（ユーザー 2026-10-15）。睡眠の Z は今のまま。
