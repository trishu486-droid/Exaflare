**確度**
- ◎ ゲームデータ由来（cactbot のタイムライン・トリガー）で、攻略記事とも一致
- ○ 複数の攻略記事で一致
- △ 資料で食い違う・1つの資料だけ・図から測った推定（実機・動画で確認したい）

時刻は cactbot のタイムライン（`dancing_mad.txt`）の秒数。P2 は 297.4 秒（P1 の終わりのセリフ）から。表の「P2 内」は 297.4 秒を 0 とした目安で、ユーザーからもらった軽減表（P2_ゴッドケフカ）の時刻とほぼ同じ（表は詠唱の始まりで書いている所があり、1秒ほどずれる）。

## 2. ミッシング（P2 の大部分）

### 2.1 しくみ
- ミッシングの詠唱完了で、**全員にスペルハザード4スタック**。頭上に予兆（**頭割り2人・円3人・扇3人**）。◎○
  - 頭割りは **タンヒラから1人・DPS から1人**。円と扇は、それぞれタンヒラかDPSのどちらかにまとまって付く（タンヒラが〈頭・円・円・円〉なら DPS は〈頭・扇・扇・扇〉、など）。○
- **塔は毎回2本、1本に2人**（1回で4人が踏む）。全部で8回。踏まない・1人しか入らないと大爆発（全体＋与ダメージ低下）。○
- 塔を踏むと、その人の**頭上の攻撃が発動してスタックが1つ減る**。スタックが残っていれば新しい予兆が付く。◎
- 新しく付く予兆：**奇数回に踏んだ4人 → 扇2・円2**、**偶数回に踏んだ4人 → 頭割り2・扇1・円1**。○（7回目・8回目は帳尻合わせで例外あり：cactbot のコメントでは、処理によっては7回目に頭割り4つ）
- 塔は毎回、**時計回りか反時計回りに 45 度ずれて出る**（2本並んで、「塔のある側」を南とみなして処理）。○
- 最後に**裁きの光**。スペルハザードが1つでも残っていると即死。◎○

### 2.2 未来の終焉／過去の終焉と消滅の脚
- 偶数回の塔と同時に、**ケフカに近い4人へ大きな円**が着弾し、**分身が3体**出る（本体と合わせて4体）。○
  - 分身の位置：近い4人とケフカの中心を結ぶ線の上、ケフカのターゲットサークル内側の線と中心の中点あたり（ぴれん氏の図）。△
  - 円が自分に来ても困らない「扇持ちと塔を踏まない人」の4人で受ける（ヤーン：扇担当2人＋近接2人）。○
- 次の奇数回の塔と同時に、**ケフカと分身3体が「消滅の脚」**。詠唱開始と同時にランダムな人の方へ向き直る。○
  - **未来**の終焉のあと＝**前方**、**過去**の終焉のあと＝**後方**に攻撃。○
  - 形：攻略記事は「半面」、ぴれん氏の説明は「扇の角度が 90°」。食い違う → △（動画で確かめたい）
  - 誘導：過去は着弾後に塔の間、未来は塔の反対側で待ち、消滅の脚の詠唱開始で動く（ヤーン）。ターゲットサークルに近すぎると角度がつきやすい。○
- 4回目（8回目の塔の後）の消滅の脚は、全員 A に集まって避ける（ヤーン）。○

## 3. トライン＋破壊の翼

- 三角形が**外周6か所＋中央1か所**の候補に降る：**1回目 外周3つ → 2回目 外周1つ → 3回目 中央＋外周2つ**。中央は必ず3回目。◎○
  - 外周の候補（cactbot の座標、中心 (100,100)）：(88.45,90) (97.11,115) (102.89,85) (111.55,110) (114.43,95) (85.57,105) → どれも中心から約 15.3。◎
  - 中央の三角の向きは東か西。◎
- 三角は降ってきた順に、**頂点3か所から円**が爆発（2秒おき）。円の半径は図から 約 6、三角の大きさ（中心から頂点）約 6。△
- **破壊の翼1回目**：半面。光っている翼の側に来るので、光っていない側へ。◎○
- **破壊の翼2回目**：一番近い人と一番遠い人に強攻撃。MT はボスに寄る、ST は最外周、ほかは最外周を踏まない外周あたり。◎○
- 安地の取り方（ヤーン）：ヒーラー・DPS は **南 → 東**、タンクは **北 → 西** の順に、1回目に降った三角の中へ。○

## 4. 採用する処理法（ユーザーの決定 2026-10-09）

**ヤーン速報の「ミッシング 優先順＋立ち位置ぴれん」**。南調整（②）は後で入れる。

出典：[絶妖星乱舞 攻略特設（ヤーン速報）](https://yan-flash.com/ultimate/yosei-ranbu) の「フェーズ2」。

- ペアを固定：**MT&H1／ST&H2／D1&D3／D2&D4**。ミッシング前に西タンヒラ・東 DPS で分かれておく。
- 頭割りが付いたペアは **1・2・3・8 回目**、それ以外のペアは **4・5・6・7 回目** に踏む。
- **奇数回**：左下（左の塔）は扇、右下（右の塔）は円。頭割りは優先順位で **ヒラ ＞ タンク ＞ 近接 ＞ 遠隔**。
- **偶数回**：左から優先順位で ヒラ ＞ タンク ＞ 近接 ＞ 遠隔。
- 塔を踏まないペアは位置固定（左タンヒラ、右 DPS）。過去未来の分身の誘導は **扇担当2人と近接2人**。
- 3回目の塔の後、自分のデバフで分岐：円なら `/mk stop <me>`、扇なら `/mk bind <me>`（マーカーで目印）。
- 8回目は、マーカーの数字（左1／右2）で踏む。
- 消滅の脚：奇数回の右の塔の頭割りが当たる報告あり → ラグビーボール（2つの塔の重なり）の右側に立つと安定。脚の誘導はターゲットサークルから少し離れる（マックスメレー）。
- 細かい立ち位置はヤーンの図（奇数回・偶数回）。実装の前に図を見て座標に起こす。

トライン：上の 3 章のとおり（ヤーン）。

## 5.5 ユーザーの動画から（2026-10-09、ミッシング中の画面録画4本・各12〜16秒）

カメラが低く（後ろから見上げる角度）、ボスの体とエフェクトで床が隠れるので、**大きさは測れなかった**。見えたこと：
- **スペルハザード**のアイコンに残りの数（4 → 3 → 2）が出る。◎
- 頭上の予兆：**扇＝オレンジの扇形のマーク**、ほかに頭割り・円のマーク。予兆は頭上に出たまま、塔を踏むと発動。○
- 塔：床の**青い輪**の上に**青い球（隕石）**が浮かぶ。2本が隣り合う。塔の位置はフィールドマーカー（1〜4、中心から約 8.5）のあたり。○
- 攻撃を受けた人に「**被魔法ダメージ増加**」が付く（同じ人が2回受けると危ない）。○
- プレイヤーは頭上に **⊘1・⊘2 などのマーカー**（`/mk stop` など）を付けて目印にしていた（ヤーンの「3回目の後の分岐」と同じ）。○
- 「過去の終焉」「未来の終焉」の詠唱 → 少しして「消滅の脚」の詠唱、の順で出た。◎
- 消滅の脚の形は、エフェクト（黄色い蹴りの軌跡）しか見えず、半面か扇かは判断できなかった。△

→ 大きさは、ヤーンの図から測った推定（2.3）で作り、開発版で触ってもらって詰める。

**トライン（2026-10-10、画面録画3本・各8〜16秒）**
- 裁きの光 → トラインの詠唱のあと、**床が金色**に変わる。○
- 三角は**黄色の半透明の三角形**で、床に大きく出る。頂点の爆発の予兆は**茶色っぽい半透明の円**（大きい）。○
- 破壊の翼（半面）：**片方の翼が白く強く光る**。そのあと「破壊の翼」（強攻撃）の詠唱。◎○
- ゴッドケフカの足元の**赤い輪（ターゲットサークル）**は大きく、フィールドマーカーの内側くらいまである。○
- 最後に「終末の双腕」の詠唱。○
