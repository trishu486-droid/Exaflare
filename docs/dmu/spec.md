# 絶妖星乱舞 シミュレーター 仕様

絶妖星乱舞（絶ケフカ）の練習ツールで決まっている仕様をまとめた資料。どのコンテンツにも共通の決まりは `docs/common-spec.md`、経緯は `docs/dmu/history.md`。

## 1. 名前・メニュー・画面

### 名前
- 「絶妖星乱舞 シミュレーター」（タイトル画面は「絶妖星乱舞 SIMULATOR」）。検索向けの説明文には「絶妖精乱舞」「シュミレーター」も残す。フェーズ名（P3・P4・P5）やギミック名は説明文・タイトルに入れない（ユーザーの決定。フェーズが増えても直さなくて済むように）。
- スキル・アビリティ・敵の攻撃・デバフは**製品版の日本語名**。英語名をカタカナにしただけの名前は使わない（例：×エッジ・オブ・シャドウ → ○漆黒の剣）。
  - ジョブの技：公式ジョブガイド https://jp.finalfantasyxiv.com/jobguide/ （レベル100で確認済み）
  - 敵の攻撃名：cactbot の日本語データ `ui/raidboss/data/07-dt/ultimate/dancing_mad.ts` の `'locale': 'ja'` の `replaceText`（時刻は同じフォルダの `dancing_mad.txt`）
  - デバフ名：ゲームのステータスデータ（xivapi の日本語データ）。なければ日本語の攻略記事。海外のまとめ記事の訳は使わない。

### メニュー
- タイトル（PRESS START）→ ケフカの顔がうっすら出て高笑い（`src/kefka_intro.ts`、約1.9秒。もう一度押すと飛ばせる。効果音オフなら鳴らない）→ ジョブ選択 → フェーズ選択（P3／P4／P5／おまけ）→ ギミック一覧 → 担当の選択など → 開始。
- ギミック一覧は左右でフェーズを切り替え。前に選んだフェーズは `opt.phase` に保存。
- フェーズ選択のボタンの下の文字は「その敵の一般的な呼び名」（P3＝エクスデス＆カオス、P4＝ネオエクスデス＆カオス、P5＝カオスケフカ）。
- **β版**（ユーザーの決定 2026-10-14）：P1・P2・P3 は、フェーズ選択のボタンとギミック選択の見出しに金色の小さな「β」を付ける（`src/menu.ts` の `BETA`）。P4 は 2026-10-16 にβを外した（ユーザーの決定：散開エフェクト・予兆の床・難しさを直したので正式版に）。
- P2・P3・P5 は一覧のいちばん下に「通し」（P2 通し・P3 通し・P5 通し）。P4 は「P4 通し」（おちょくりソウル）の1つだけ。P5 通しは以前は隠しコマンドだったが、今は常に出す。
- ギミックごとに i マークで解説（`src/info.ts`）。リザルトでは Y で解説。
- ジョブは8つ：ナイト(MT)・暗黒騎士(ST)・モンク(D1)・リーパー(D2)・機工士(D3)・黒魔道士(D4)・占星術師(H1)・学者(H2)。技は `src/jobs.ts`。

### 上の並びと左上の表示
- ≡（ギミック選択へ）／王冠（ランキング）／ベル（お知らせ）／手紙（お問い合わせ）／⚙（設定）。いつも表示。

### 画面の配置

- **下の帯**（2026-10-29 ユーザー）：詠唱バーと技名だけ。進行・DMG・HIT の文字は出さない（帯の高さ `--status-h` も 40〜54px → 26〜32px）。左にだけ、P1 のタンクのバフ回しの案内（補助表示 ON のとき）。
- **ボスの残り HP の割合**：通し（ボスの HP があるもの）だけ、画面の一番上の HP のバーの右下に「ケフカ 85.2%（目標 15%）」（目標は `hpGate` があるとき）。出している間は、左右の列（バフ・敵視リスト）を少し下げる（`.gb.hpon`）。
- ミッシングの塔の着弾は、数字ではなく、玉が上から塔の真ん中へ降りてくる高さで見せる（少し透けた玉・足元に薄い影。2026-10-29 ユーザー）。
- 画面の外枠の大きさは、どのフェーズでも同じ。
- P5 型：上の帯（左＝バフ・デバフ、右＝敵視／HP）＋横いっぱいのフィールド＋下に詠唱バーと HUD。チャット欄なし。
- P4 型（`.gb.p4on`）：上の帯＋フィールド（上下の星空を切って大きく）＋詠唱バーと HUD＋チャット欄（左7割＝PT マクロ、右3割＝自分のメモ）。P3 もマクロ欄を使う。
- 同時に詠唱しているものは、詠唱バーの上に積む。
- ボタン（チャット欄の下の4つ）の名前はギミックごと（`buttons`）。使わないボタンは灰色。P4＝早 散開／遅 散開／止まる／動く（PC は 5〜8 キー）。P3＝ターゲット切替／（タンク前半）LB3・攻撃／バインド／禁止。
- 結果画面：デバフ・敵視・詠唱バーを消し、フィールドを暗くする。被弾の内訳・ランク・DPS。P4 の結果は枠の中でスクロール。
- スマホ：本体を画面の高さにちょうど収まる大きさにする（`src/fit.ts` が二分探索で測る。下限 225px・上限 640px）。ホーム画面から開いたときは `html.app` で上の余白を「時計の表示の高さ＋22px」に。横向きはゲームボーイアドバンス風（左にスティック・右にボタン）。
- ページが見えなくなったら BGM と効果音を止める（戻ると続きから）。
- 大きな攻撃の光・被弾の赤い光は、画面全体に出す。

## 2. 共通の機能

- **お知らせ**（`src/news.ts`、ベル）：日時（日本時間・分まで）と内容を新しい順に全部。未読はベルの赤い点と NEW（端末の `newsSeen` に、最後に見たいちばん新しい日時を保存）。**本番に出すたびにいちばん上に1件足す**（遊ぶ人向けの短い言葉で。日時は `TZ=Asia/Tokyo date '+%Y/%m/%d %H:%M'`）。
- **お問い合わせ**（`src/contact.ts`、手紙）：ニックネーム（任意・12文字）と本文（1000文字）だけ。Google フォーム「絶ケフカシミュ問い合わせ」（ユーザーの Google アカウント）へ `no-cors` で送る。ジョブ・フェーズ・ギミック・端末・画面サイズ・ホーム画面か・版（お知らせの最新日時）・UA を自動で添える。返信はしない。送り先の ID（`entry.312787377` ニックネーム、`entry.16255419` 本文、`entry.613677479` 自動情報）は触らない。
- **ランキング**（`src/ranking.ts`、王冠）：Firestore の REST API。DPS 順・Perf（同じギミック・同じジョブの中での位置）・登録日（月/日。押すと分まで。サーバーの `created_at`）。被弾0・速度100%・補助表示なしの記録だけ登録できる。
  - ギミックの選択肢はフェーズごとにまとめ（`<optgroup>`「P1（ケフカ）」〜「P5（カオスケフカ）」の順）、名前の前にフェーズを付ける（例「P5 ミッシング」）。対象は `RANK_GROUPS` に書いたものだけ（2026-10-29 ユーザー。前は P3 の部品や全通しまで混ざっていた）。`rankBlock` は `RANK_GROUPS` にないギミック（P3 の部品・全通し）を対象外にする。
  - 対象は P1〜P5 の、メニューに出るギミックすべて（2026-10-30 ユーザー「ランキング P4 以前のも作っていいよ」。前は P5 だけ）。`docs/firestore.rules` の `d.mech in [...]` に `p1a, p1b, p1c, p1, p2m, p2t, p2, p3a, p3c, p3d, p3, p4` を足した。**Firebase のルールに貼って公開するまで、P1〜P4 の登録は「送れませんでした」になる**（読むのはできる）。
  - Firebase の無料枠は読み込み1日5万回。人気が出たら Perf の計算をまとめるなどで減らす。
- **設定**（⚙）：基本（表示の項目もここ）・サウンド・ギミック・操作（3D のカメラ・ゲームパッド・キーボード〔PC のみ〕）の4つのタブ（2026-10-30 ユーザー：タブを減らす。前は基本・表示・ギミック・サウンド・キー・情報）。「非公式・非営利。スクウェア・エニックスとは無関係」「BGM はオリジナル」「Cloudflare Web Analytics（Cookie なし）」などは、設定の情報タブからお問い合わせ（手紙）の画面のいちばん下「このツールについて」に移した。
- **お知らせ**（ベル）：1行目が見出し、「・」の行が箇条書き、「・ほかに：」は小さく薄く（`news.ts` の `body`。2026-10-30 ユーザー：見づらい・簡潔に）。
- **BGM**：すべてオリジナル曲（`src/audio.ts`・`src/bgm_*.ts`）。既存の曲のメロディは使わない（日本ファルコムの曲は規約でゲーム利用が禁止）。
  - P1〜P4 はフェーズごとに曲が決まっていて自動で流れる（`bgm.use`。2026-10-15、実機の曲の分け方に合わせた）。P5 は設定で選んだ曲。
    - P1：「神々の塔」第一〜第三楽章（`src/bgm_p1.ts`）。区切り（神々の像 第一〜第三楽章）ごとに曲が変わり（P1 通しでは塔が動き出す時に次の楽章の曲へ）、塔の足元 → 中腹 → 頂上を表す。第一＝嬰ハ短調・58、第二＝ハ短調（長調と入れ替わる）・130、第三＝嬰ハ長調・172。
    - P2：「堕ちる星」（`src/bgm_set2.ts`、イ短調・136）。低音がよく動き、低い音が厚い。
    - P3・P4：「魔導の祭壇」（`src/bgm_set2.ts`、嬰ハ短調・103）。ホとヘの保続音の前奏（1回だけ）→ オルガンが低い所でうねる本編。
  - 作り方：ユーザーが送ってくれた実機の曲の録音から、テンポ・調・和音の進み方・低音の動き・音の厚み・打楽器の量を機械で分析し、その雰囲気だけを借りて旋律・和音の並びは新しく作る。
  - もと P4 の曲「紅き疾走」（`src/bgm_rush.ts`）と、その候補だった「混沌への決戦」（`src/bgm_p4.ts`）は、設定で選べる曲として一覧に残している。
- **ホーム画面に追加**（PWA）：`public/sw.js`。公開先（`pages.dev`・移行中は `github.io`）でだけ登録する（`src/pwa.ts`）。

- フィールドの床：2y のます目・斜め線はやめて、実機の床に寄せた模様にする（2026-10-17 ユーザー。`gfx.ts` の `FLOOR`・`floorCanvas`）。P1〜P4 は中心から外へ同じ向きに渦を巻く線（P2 は金色、P1・P3・P4 は青。P1 は金をやめて青にした 2026-10-17 ユーザー）。P5 はさびた鉄板（輪と放射の継ぎ目・すべり止め・びょう、外周も茶色）。どのフェーズかは `sky.ts` の `withFloor`（`inst.floorTheme`）で決める。つなぎ目の中で次のフェーズに替わると床も替わる。
- 画面全体にかかる演出（白く光る・色が変わるなど）は、フィールドの下の帯（詠唱バー・DMG・HIT）にもかける（2026-10-17 ユーザー）。フィールドの外まで描く上の層（`hud.ts` の `topLayerDraw`・ギミックの `drawTop`）は、画面の上の端から下の端までの大きさ。攻撃の光（`fxFlash`）と P2・P3 の全体攻撃（`p2fx.ts` の `screenFx`）は、もともと画面全体にかかる。
- 近接ジョブの届く範囲（マックスメレー）の円は出さない（2026-10-17 ユーザー。前はターゲット中のボスのまわりに薄い紫の円を出していた。`action.ts` の `drawActFx`）。

## 2.4 P1（ケフカ）※β版（2026-10-18 に本番へ）

## 6. ギミックの作り方（共通の形）

ギミックは `src/mech_*.ts` に1つずつ。`mech_exa.ts`（短い）と `mech_p4.ts`（通し・大きい）を手本にする。

```ts
const X = (() => ({
  id:'…', name:'…', sub:'…', view:24, start:{ x:0, z:4 }, slots:true, // slots：担当（MT/ST など）を選ぶか
  gen(){ /* 毎回ランダムなパターンを作って返す */ },
  create(pattern){
    return {
      end: 120,                               // 終わりの時刻（秒）
      casts: [{ name:'…', start:0, len:5 }],  // 詠唱バー（製品版の名前）
      progress: t => '…',                     // 上の段に出す進行表示
      tick(t){ /* 判定。当たったら hurt('理由') */ },
      draw(t){ /* フィールドに描く（gfx.ts の px(), ring(), disc() など） */ },
      // 必要なら：drawFloor, safe/safeActive, guide, status, enmity, tankRole, bossHp/hpGate, intro, countdown, t0,
      //           activeTime, resultExtra, chat/say, buttons, killAfter, enrageName
    };
  },
}))();
```

- 座標：フィールドの中心が (0,0)、半径 20。北が z マイナス。`px(x)` で画面のドットに。
- 被弾：`hurt('理由')`（`gfx.ts`）。ヒーラーへのダメージ：`healerHit(ダメージ, '攻撃名')`（`action.ts`）。
- 新しいフェーズを足すときは `src/mechs.ts`（ギミック一覧・`phaseOf`・`menuMechs`）と `src/menu.ts`（`PHASES`・左右の切り替え）に足す。

## 8. テストのしかた

- 型チェック：`npm run check`、ビルド：`npm run build`（`main` へのプッシュでも Actions で走る。落ちると公開されない）。
- 開発サーバー：`npx vite --port 5179`（バックグラウンドで。時間が来ると止まるので、要るときに起動し直す）。
- `http://localhost:5179/?debug` で `window.__T`（`S`, `opt`, `begin`, `pressKey`, `job`, `sfx`, `BGM_TRACKS` など）。
  - 例：`__T.opt.mech='p3'; __T.opt.job='rpr'; __T.begin();`。`window.__noHurt=1` でミスを数えない。タイトルを抜けるには最初に Enter（演出が約2秒）。
- Playwright：`require('/opt/node22/lib/node_modules/playwright')`、`chromium.launch({ executablePath:'/opt/pw-browsers/chromium' })`。スマホは `newContext({ viewport, hasTouch:true, isMobile:true })`。外部通信は `ignoreHTTPSErrors:true`、ランキングは `page.route` で偽のデータを返す。
  - よく使う画面：iPhone SE 375×667（バーあり 375×548）、iPhone 390×844（バーあり 390×664）、大きい iPhone 440×956、Android 412×915、iPad 820×1180。
  - 音：`--autoplay-policy=no-user-gesture-required` で `__T.sfx.ac.state` を見る。`OfflineAudioContext` に書き出して WAV にし、ユーザーに聴いてもらう。
- 全ジョブ・全担当で「正しく動けば被弾0」になる自動プレイを回す。
- 作業用のファイル（テストのスクリプト・スクショ・動画のコマ）はスクラッチパッドへ。リポジトリに入れない。
