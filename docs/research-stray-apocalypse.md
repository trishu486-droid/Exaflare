## 2. 座標系とフィールド

- フィールド中心 (100, 100)。X＝東、Z＝南（FF14 のワールド座標）。 ◎
- 円形フィールドで半径は約20と推定。Splatoon の候補点は最大半径19、線AoEの長さは±20。 △
- 以降、次の2つの回転座標を使う。 ◎
  - **u = (x − z)**：北西から来るレーンの横位置
  - **v = (x + z − 200)**：北東から来るレーンの横位置
  - 実距離は値を √2 で割ったもの。

## 3. エクサの形（レーン構造）

- 北西のエクサは南東へ、北東のエクサは南西へ、斜め45°に直進する。 ◎
- **1方向あたり6レーン**。レーンの横位置は u（または v）＝ −25, −15, −5, +5, +15, +25。 ◎△
  - 実距離では中心から ±3.54 / ±10.61 / ±17.68。レーン間隔は 7.07（= 5√2）。
- 発生位置は中心から 24.75（= 35/√2）離れたフィールド外。 ◎
  - 例：北西の u=−15 レーンは (75, 90)、北東の v=−15 レーンは (110, 75)。
- 1発ごとに 7.07 前進する（x, z がそれぞれ ±5）。 ◎
- 着弾円の半径は6。 ◎
- **予兆はフィールド外の発生地点に出る**（実機の配信スクショで確認）。オレンジの円に白い「>>>」が進行方向を指す。
  - 4つの予兆（今のセット＋次のセット）が同時に見える時間帯がある。
- 着弾は1本6発。6発の中心は中心軸上 −17.7 〜 +17.7 に対称に並ぶので、ちょうどフィールドを横断する。 ◎
  - Splatoon のプリセットは7発目まで描画しているが、7発目は中心から25以上離れておりフィールド外。
- 着弾点はすべて (100+5a, 100+5b)、a+b が奇数の格子点に乗る。 △（計算上の帰結）
- 円は 7.07 間隔・半径6で重なるので、レーンは連続した帯になる。帯の半幅は 4.85〜6。

### 1セットの形（パターン）

- **1セット＝同じ方向から2本**。 ○◎
- 光るのは **レーン i と i+3 の組み合わせのみ**なので、パターンは3種類。 △（ほぼ確定）

  | パターン | 光るレーン（u/v） | 安全帯（おおよそ） |
  | --- | --- | --- |
  | A | −25 と +5 | 2本の間（−16.5〜−3.5）と、+13.5 より外側 |
  | B（中央対称） | −15 と +15 | 真ん中（\|u\| < 6.5）と両端 |
  | C | −5 と +25 | A の鏡像 |

  - 根拠：Splatoon の近接用スクリプトは各方向3つのエクサ座標しか見ていない。これで一意に判定できるのは i/i+3 モデルの場合だけ。
  - このモデルで、同スクリプトの安置9通りすべてが安全になることを数値検証した。
- 同じ方向の中では A・B・C が1回ずつ出て重複しない（既存の練習ツールの記述）。 △要確認
- 2本の間には最低1レーン空く（日本語記事）。i/i+3 なら常に2レーン空くので矛盾しない。

## 4. 出現順とタイミング

- 6セットで、北西と北東が交互に来る（北西3回・北東3回）。 ○
- 最初が北西か北東かはランダム（英語ガイド「NE or NW」）。 △
- 時間は **1セット目の予兆（BB3C 詠唱開始）を t=0** とした値。 ◎（Splatoon の定数と cactbot で整合）

| 事象 | 時刻 |
| --- | --- |
| セット k（k=0..5）の予兆開始 | 2.5k |
| 予兆の長さ（詠唱） | 約3.9秒 |
| セット k の1発目 | 4.6 + 2.5k |
| 発射間隔 | 0.51秒（1〜6発目で約2.55秒） |
| セット k の6発目 | 7.15 + 2.5k |
| 最終セットの終わり | 約19.7 |
| Stray Entropy | 詠唱開始 16.2、散開着弾 21.0〜21.9 付近 |

- 予兆は常に「今着弾中のセット」と「次のセット」が重なって見える。予兆は2.5秒ごとに出て約3.9秒続くので、2セット分が同時に表示される時間帯がある。
- エクサの速度は 7.07 / 0.51 ≒ **13.9 y/s**。プレイヤーの移動速度（6 y/s）の2倍以上。
- 「スナップショットが早い」「見た目より先に判定が来る」という記述が多い。ダメージ判定がエフェクト表示より先に来るため、特に北西側は余裕が少ない。 ○

## 5. 主な攻略法

1. **4点避け（近接アップタイム）**
   - ボスのターゲットサークル内、中心から5離れた東西南北の4点（(100,95) など）で待つ。
   - エクサが中央を通過したら、時計回り（または反時計回り）に隣の点へ移る。隣の点までは7.07で約1.2秒。
   - Splatoon の Stray_Apocalypse_Melee はこの点を表示している。 ◎
2. **中央避け**：「4点避けではない」方式を解説した動画がある（未確認）。
3. **間に入って横移動**：最初のセットの2本の間に立ち、次のセットの隙間へ横移動する（英語ガイド）。
4. 最終セットでは、エクサ回避を優先しつつ Stray Entropy のために散開する。レンジは外周、近接は内側。

# P5 その他のギミック（練習ツール実装メモ）

出典：cactbot タイムライン、Splatoon（P5_Chaotic_Flood_Guide.cs）、AnoMech（Scenarios/Umad/P5Flood・P5Celestriad・UmadP5ForsakenNull）。

## フラッド（カオティックフラッド）

- 斜めの帯（幅10y・長さ40y）が2方向（北西→南東 ／ 北東→南西）× 各4レーン。帯の中心は ±5y / ±15y。 ◎
- 予兆は 0.4秒 + 1.02秒×k（k=0..3）に1.2秒ずつ。着弾は各予兆の6.05秒後（1.02秒おきに4回）。 ◎
- 各回2本。1回目の方向は `+5 と −15`（または反転で `−5 と +15`）、3回目はその裏側（`+15 と −5`）。2回目・4回目はもう一方の方向で同様。 ◎
- 最初の方向と各方向の反転はランダム。 ◎
- 各回に非タンクへの6y頭割り（Chaotic Flood）もあるが、ソロ練習では省略。

## スリースターズ

- 塔9本：半径10、北から20°・40°刻み、時計回りに ファイア3本 → サンダー3本 → ブリザド3本。 ◎
- デバフ（各属性2人・なし2人、20秒）は6.1秒に付与。 ◎
- 3セット：点灯 6.1 / 14.4 / 20.6、着弾 14.18 / 20.5 / 26.34。各セット4本（2属性は1本、1属性は2本。2本になる属性は3セットで1回ずつ）。 ◎
- 入る塔：デバフ持ちは「自分の属性の時計回り隣 → さらに隣 → 自分の属性」。なしは2本ある属性のもう1本。 ○
- 二択のカタストロフ（1・3セット目、4.0秒詠唱）：クエイク＝ボス中心10yの円 ／ トルネド＝10yより外のドーナツ。 ◎
  - 杖の色との対応（緑＝ドーナツ／黄＝円）は攻略記事の記述。AnoMech では未確認扱い。 △
- 塔の踏み範囲は半径3yと推定。 △
- 塔を踏むと、その属性の耐性低下が20秒付く（最初のデバフと同じもの）。同じ属性を続けて踏めないのはこのため。 ◎

## ミッシング（P5 時間切れ前）

- ミッシングの詠唱後、約8.15秒ごとに4ラウンド。 ◎
- 各ラウンド：3×3（13.5y四方）の床のうち2枚に予兆 → 約5.65秒後に消滅（落ちると即死）。 ◎
- 同時に誰か1人の足元に紫の床（約1.9秒後に危険、以後残る）と頭割り。 ◎
- 消える順（実戦ログ1件）：南西+中央 → 南東+北東 → 北+北西 → 南+東。最後に西だけ残る。 △（ランダム性は未確認）
- ログでのパーティの立ち位置：南 → 西寄り(-7,6.75) → 北西寄り(-6.75,-6.75) → 北東寄り(7,-6.75) → 西。 ◎

## 狂気のオーケストラ（1回目、β）

- cactbot：狂気のオーケストラ → 0.9秒後にホーリー → 3.2秒後にもう一度 → 0.9秒後にホーリー → 約3.5秒後にカオティックホーリー / フレアディフュージョン。 ◎
- 1回目：タンク以外6人からランダム3人にホーリー（半径5y、重なると即死。被魔法ダメージ増加が付く）。同時にMT・STに強攻撃、ヘイト1位にフレア・2位にホーリー（7秒）。 ○
- 2回目：ボスに近い3人にホーリー。1回目で当たらなかった3人がタゲサに入る。タンクは北で頭割り（タゲサに入らない）。 ○
- 最後：フレアのタンクは北端へ（近くの人が即死する距離減衰）、ホーリーのタンクはボス前で無敵。ほかは南で待機。 ○
- 立ち位置は kanatan.info の攻略図から読み取り。詠唱の長さ・予兆が出るタイミング・フレアの危険範囲（8yとした）は推定。 △
