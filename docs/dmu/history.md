## 2026-10-09 リポジトリと公開先の片付け

- 公開先を Cloudflare Pages（https://dancing-mad-sim.pages.dev/）に移すことにした。理由：リポジトリを非公開にしても無料で公開できる（GitHub Pages は無料プランだと公開リポジトリだけ）、URL が短い、ブランチごとに開発版の URL が付く、容量・通信量の心配がほぼない。
  - 新しい住所でも、ランキング（Firebase）・お問い合わせ（Google フォーム）・アクセス解析はそのまま動くことを確認。
  - `src/pwa.ts`（ホーム画面追加のオフライン対応を pages.dev でも）と `index.html`（canonical・og:url・og:image を新しい住所に）を直した。お知らせで新しい住所を案内。
  - 独自ドメインは今は買わない（コンテンツが増えて同じ住所で続けたくなったら検討）。
- ブランチを `main`（本番）と `dev`（開発）の2本に整理。P3・P4 の開発ブランチ（`p3-dev`・`p4-dev`）はやめた。
- 資料を `docs/README.md`（入口）・`docs/common-spec.md`（共通）・`docs/dmu/`（仕様・経緯・調査）に組み直した。セッションごとの引き継ぎ資料（`handoff-main.md`・`handoff-p3.md`・`handoff-p4.md`）は、中身をこの3つに振り分けて消した。
- 開発版の確認は Artifact ではなく、Cloudflare のプレビュー（`dev` ブランチ）で見る方針にした。

## 2026-10-06〜07 スマホの画面まわり（本番セッション）

- スマホで本体を画面の高さにちょうど収まる大きさに（`src/fit.ts` が開いたとき・向きを変えたとき・Safari のバーが出入りしたときに二分探索で測る。下限 225px・上限 640px）。高さが足りないときは画面の中を詰めてフィールドを大きく出す。
- お知らせなどの画面（`.sheet`）：上下左右をセーフエリアの分あけ、「とじる」を下に貼り付ける。
- ホーム画面から開いたとき（`html.app`）は上の余白を「時計の表示の高さ＋22px」に。開いた直後・戻ってきたときにも測り直す。
- ページが見えなくなったら BGM と効果音を止める（戻ると続きから）。
- スマホの横向きにゲームボーイアドバンス風の配置を追加（左にスティック・右にボタン。P4 はチャットが下）。
- 被弾の赤い光・大きな攻撃の光を、フィールドから画面全体に移した。
- ホーム画面のアプリでの本当の見た目・音の止まり方は、この環境では確かめられないので、ユーザーに実機で見てもらっている。

## 2026-10-05〜06 P5 の調整・お知らせ・お問い合わせ

- **P5 通し**：隠しコマンド（↑↑↓↓←→←→BA）をやめ、P5 のギミック一覧のいちばん下に常に出す。ランキングも「？？？」にしない。
- **AA の大きさ**：動画と画像をターゲットサークル（半径8）を物差しに測り、今の判定（タンク3・ヒーラー／DPS 4）で合っていると確認。Splatoon では混沌の渦が半径5（ツールは4のまま。未決）。
- **エクサ**：友達の「見下ろしだと簡単。実機は判定がクソ早い・2方向と1方向から来る」を精査。時刻・形は Splatoon のスクリプトと一致していて、違いは見た目（床が残る・光と破片・カメラ）だとわかった。床を 0.9 秒残す・床の光と破片を足す・爆発の見た目を遅らせる、を入れた。遅らせる秒数は 0.5（早すぎ）→ 0.25 → 0.15 → 0.1 とユーザーが触って決めた。画面全体の光は、赤魔の攻撃エフェクトと混同しないため入れない。
- **ミッシング**：友達の「4回目まで必ず時計回り、例外はない」を受けて、3回目に北（A）の穴が出ないようにした（北は4回目の予兆だけ。ユーザーが動画で確認）。前に集めた実戦ログと raidplan A では3回目に北が消えていて合わない（東西南北の読み違いの可能性が高いが未確認）。
- **お知らせ**（ベル）と**お問い合わせ**（手紙、Google フォーム）を追加。ランキングに登録日を表示。プレイ中の左上の名前を2行に（6案から選んでもらった）。
- アクセス解析の質問：Cloudflare Web Analytics も Search Console も滞在時間は出ない。GA4（Cookie あり）か Firebase に記録する案（提案：Firebase）。未着手。
