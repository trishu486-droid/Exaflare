# P4 開発の引き継ぎメモ

次のセッションで続きをやるためのメモ。P4 は本番 `claude/ff14-exaflare-trainer-3ssqps` に反映済み（GitHub Pages に公開）。開発の続きは `p4-dev` ブランチで。

## 進め方のルール（ユーザーと決めたこと）

- 返事は日本語。8bit の見た目を守る。BGM はオリジナル曲だけ。
- **コミット・プッシュは、ユーザーが「いいよ」と言ってから。勝手にしない**（作業途中の保存も、フックに言われたときも、先にユーザーに聞く）。途中の確認は開発版の Artifact を更新して見てもらう。
  - 開発版 Artifact：https://claude.ai/artifact/Sx4VAZmevGwWZqtZKRsE5S（`npm run build:artifact` → `dist-artifact/index.html` から Cloudflare のタグ・manifest・OGP を外し、title を「絶ケフカ P4 開発版」にして公開）
  - 本番の Artifact（UL6qtX9MmHjywEf9mqpmQN）は古い版のまま（本番は GitHub Pages）。
- 見た目を変えるもの（絵・アイコン・エフェクト・ボタン）は、**まずイメージ画像で提案 → OK が出てから実装**。
- 公式の画像は使わない。参考画像・動画を見て、色・形・配置を寄せて手描き（コードで描く）する。
- スクリーンショットはリポジトリに保存しない。リポジトリにモデル名を書かない。

## 名前とメニュー

- 名前は「絶妖星乱舞 シミュレーター」（タイトル画面は「絶妖星乱舞 SIMULATOR」）。検索向けの説明文には「絶妖精乱舞」「シュミレーター」も残す。
- メニュー：タイトル → ジョブ選択 → フェーズ選択（P4／P5／おまけ）→ ギミック一覧。ギミック一覧では左右で P4・P5 を切り替え。前に選んだフェーズは `opt.phase` に保存。
- タイトルを押した後：ケフカの顔のドット絵（40×48、`src/kefka_intro.ts`）が暗闇に一瞬うっすら（不透明度 0.3）出て高笑い（合成音「ヒャー ハッハッハッ」。もらった笑い声の音を図にして、高さ・響き・間隔・エコーを寄せた）→ 約1.9秒でジョブ選択へ。演出中にもう一度押すと飛ばせる。笑い声は効果音の設定がオフなら鳴らない。

## 画面のレイアウト（全ギミック共通）

- 画面の外枠の大きさは P4 も P5 も同じ。
- P5 など：上の帯（左＝デバフ・バフ、右＝敵視／HP）＋横いっぱいのフィールド（画面の高さの真ん中）＋下に詠唱バーと HUD の段。チャット欄はなし。
- P4：上の帯＋フィールド（上下の星空を切って大きく、帯と詠唱バーの段の間）＋詠唱バーと HUD ＋チャット欄（左7割＝PT マクロ、右3割＝自分のメモ）。
- 同時に詠唱しているものは、詠唱バーの上に積む。
- 結果画面：デバフ・敵視・詠唱バーを消し、フィールドを暗くする。P4 の結果は枠の中でスクロール。
- メモのボタン4つ（早 散開／遅 散開／止まる／動く）。フィールドの下に細い1列で置く。ランプはなし（押したメモはチャット欄の右に流れる）。P5 でも同じ場所に置くが割り当てなし。PC は 5〜8 キー。リザルトでメモの答え合わせはしない。
- 本体の高さを詰めた（スマホ幅 390px で 810→約730px）：スティック 114px・ABXY 54px、上の余白・段の間・画面の枠を少し細く。SELECT/START は元の位置と余白のまま。スマホは本体の幅を (画面の高さ − 24px) × 0.43 までにして、iPhone SE（375×667）でもスクロールなしで収まる。

## P4 の仕様で決まったこと

- 味方7人は画面に出さない（内部では決まった位置に立つ）。
- 散開：自分の側（1セット目はネオエクスデスの方向が北、2セット目は真北。タンヒラ西・DPS 東）にいて、誰も巻き込まなければ正解。範囲は半径6。
- 頭割り：自分の組の頭割りの人から6以内、散開に巻き込まれない。
- 視線：視線持ちはケフカのターゲットサークル（半径8）の中、ほかは外。本当ならケフカを見ない、嘘なら見る（正面±45°）。向きは足元の輪の黄色い三角。向きは最後に動いた方向で、敵を攻撃した瞬間（攻撃の GCD・アビリティ、攻撃魔法の詠唱の始まり）はケフカの方を向く（実機と同じ）。バフ・回復では向かない。
- 加速度：爆発の瞬間に「移動・詠唱中・スキル使用から0.6秒以内」なら動いた扱い。ミスしたときだけ打ち上がる演出。
- 事前に見えるもの：なぞなぞマジック等の予兆、ケフカの輪の玉（上の紫＝サンダガ、下の青＝ブリザガ）、無の氾濫はネオエクスデスの位置と左右の目印（紫＝ピンクの六角形の泡、青＝白い氷の逆三角の泡）だけ。色の地帯・生死の境界・混沌の炎／水の範囲は着弾まで見せない。
- ボスは外周の少し内側（中心から17）。おちょくりソウルは詠唱バーだけ（演出なし）、約10秒でボスが出る。
- デバフの並び（実機の画像から）：傷 → フィールド／超越 → 呪詛 → フォーク／水圧縮 → 加速度 → 炎と水（炎と水の順は人によって違うので毎回ランダム）。

## BGM

- P4 の曲は「紅き疾走」（`src/bgm_rush.ts`、オリジナル曲）。アクションRPGのボス戦風の疾走ロック。ホ短調・BPM176、イントロ4小節＋ループ A（4）→ B（8）→ C（8）→ D（8）＝ 28小節・約38秒。バイオリンは大きめ。
- ギミックが P4 のときは `bgm.use('p4')` で自動でこの曲（audio.ts の P4_TRACK）。設定の BGM 一覧の一番下にもある。
- 候補だった「混沌への決戦」（`src/bgm_p4.ts`、ト短調・BPM142・16bit プログレ風）も一覧に残してある。
- 追加した音色：sbrass／sbrass2（シンセブラス）、slap／pop（スラップベース）、rorg／rorgA（ロックオルガン）、ohit（オーケストラヒット）、riff／violin／violin2／piano／syn。
- ファルコムの曲は規約（第4条3項）でゲームへの利用が禁止なので使えない。
