# 絶妖星乱舞（絶ケフカ）P4「おちょくりソウル」調査メモ

P4 を練習ツールに入れるための仕様調査（第2版）。まだ実装はしない。

**確度**
- ◎ ゲームデータ由来（cactbot のタイムライン・トリガー、AnoMech の再現シナリオの秒数・座標・形）で、攻略記事とも一致
- ○ 複数の攻略記事で一致
- △ 資料で食い違う・1つの資料だけ・推定（実機・動画で確認したい）

時刻は「おちょくりソウル」の詠唱開始を 0 秒とした目安（AnoMech の再現ログ）。cactbot のタイムラインでは 1100.0 秒がおちょくりソウル完了。

## 3. なぞなぞマジック／マジックチャージ／マジックアウト

### 形（AnoMech の再現データ）

| 技 | 形 | 確度 |
| --- | --- | --- |
| ひろげるブリザガ | 中央から斜め4方向（北東・南東・南西・北西）へ 90° の扇が4つ。フィールド全体を4等分。**向かい合う2つ** が予兆 | ◎ |
| もりもりサンダガ | 幅 10 の平行な帯が4本。向きは斜め（北東〜南西方向か北西〜南東方向の2通り）。4本でフィールド全体を覆い、**1本おきの2本** が予兆 | ◎ |

### 本当／嘘

| | 本当 | 嘘 | 確度 |
| --- | --- | --- | --- |
| ブリザガ | 予兆の扇を避ける | 予兆の扇に入る | ◎ |
| サンダガ | 予兆の帯を避ける | 予兆の帯に入る | ◎ |

サンダガとブリザガは別々に本当／嘘が決まる。安地は「扇の答え」と「帯の答え」が重なる場所（なぞなぞマジック 1〜3 は予兆と同時に処理）。◎

### マジックチャージ → マジックアウト

| 項目 | 内容 | 確度 |
| --- | --- | --- |
| ため | 68 秒のマジックチャージの後、74 秒のサンダガと 92 秒のブリザガは普通に着弾し、その本当／嘘がためられる | ◎ |
| マジックアウト | 新しいサンダガ＋ブリザガの予兆と玉が出る | ◎ |
| 答え | サンダガ・ブリザガそれぞれで、**ためた時の本当／嘘とマジックアウトの本当／嘘が同じなら本当、違えば嘘**（嘘をためて嘘で出すと本当） | ◎○ |
| 同時に | 混沌の水の円／ドーナツと同時に処理する（水がドーナツなら内側の安地、円なら外側の安地） | ◎○ |

## 4. グランドクロス1・2 のデバフ

### 意味（グランドクロスの玉で本当／嘘）

| デバフ | 本当 | 嘘 | 確度 |
| --- | --- | --- | --- |
| 加速度爆弾 | 切れるとき **動かない**（2 秒前には止まる。ターゲット解除・納刀） | 切れるとき **動く** | ◎○ |
| フォークライトニング | **1人受け（散開）** | **頭割り** | ◎○ |
| 水属性圧縮 | **頭割り（3人）** | **1人受け** | ◎○ |
| 呪詛の叫声 | 全員 **見ない**（外を向く） | 全員 **見る**（内を向く） | ◎○ |

- 本当／嘘は、そのデバフを付けたグランドクロスの回で決まる（1回目と2回目は別）。◎
- 視線は前方 90° に相手が入ると「見た」扱い。見てしまうと石化（2 秒で解除、即死ではない）。◎○

### 配られ方

| | 1回目 | 2回目 | 確度 |
| --- | --- | --- | --- |
| 呪詛の叫声 | タンヒラ1・DPS1 / 60 秒（必ず **視線1**） | タンヒラ1・DPS1 / 69 秒（必ず **視線2**） | ◎○ |
| フォークライトニング | タンヒラ1・DPS1 | タンヒラ1・DPS1 | ◎○ |
| 水属性圧縮 | タンヒラ1・DPS1 | タンヒラ1・DPS1 | ◎○ |
| 加速度爆弾 | 4 人（早2・遅2） | 4 人（早2・遅2） | ◎○ |

- フォークライトニングと水属性圧縮は、同じ回なら同じ秒数。**1回目が早（1分未満）なら2回目は遅（1分以上）**、その逆も。◎○
- 早は約 71 秒、遅は約 96 秒にそろって切れる。どちらの回で付いたかではなく、残り秒数で1セット目か2セット目かを判断する。◎○
- 1人が持つのは、加速度爆弾・水かライトニング・叫声それぞれ最大1つまで。◎○
- 同じ回で付いても、叫声は1セット目、水圧縮は2セット目、のように分かれることがある。◎○
- 頭割りは 3 人（そのロールの散開役以外の3人）で受ける。被魔法ダメージ増加が付く。◎

## 5. ほのお・つなみ（混沌の炎・混沌の水）

| 項目 | 内容 | 確度 |
| --- | --- | --- |
| 付く順 | 1回目がほのおかつなみかはランダム | ◎ |
| 処理の順 | 必ず **混沌の炎（1セット目の後）→ 混沌の水（最後）** | ◎○ |
| 着弾 | デバフが切れた瞬間の位置に半径 6 の範囲が確定し、数秒後に着弾 | ◎ |
| 混沌の炎 | 本当＝**円**（デバフが消えたらすぐ離れる）、嘘＝**ドーナツ**（予兆が見えるまで動かない） | ◎○ |
| 混沌の水 | 本当＝**ドーナツ**、嘘＝**円** | ◎○ |
| 処理 | 全員で中央に集まって置く | ○ |
| 注意 | ドーナツのときデバフが消えた瞬間に動くと、まだ判定が出ていないので当たって死ぬ | ○ |

| 人数 | 4人ずつ（タンヒラ2・DPS2 がアラガンフィールド）とする資料と、「必ず4人ずつとは限らない」とする資料がある | △ |

| 判断（無の氾濫が本当） | アラガンフィールド → **自分の傷と違う色** を受ける。死の超越 → **自分の傷と同じ色** を受ける | ◎○ |
| 判断（無の氾濫が嘘） | 上の逆 | ◎○ |

| 人数の偏り | 左右が4対4になるとは限らない | ○ |

## 8. 練習ツールに入れる案（実装はまだ）

P5 は「動き」が中心、P4 は「覚えて判断」が中心。

1. **デバフ判断クイズ**：玉とデバフを見て「散開？頭割り？動く？止まる？見る？見ない？」を答える
2. **なぞなぞマジック**：扇＋帯の予兆と玉を見て安地へ（マジックアウトの計算も）
3. **無の氾濫**：傷の色・アラガン／超越・玉から左右を選ぶ
4. **P4 通し**：120 秒すべて。最後に 25% の DPS チェック
